## 👋 About Me

I'm **Arsh**, a full-stack developer based in **New Delhi, India** who specialises in building **production-ready Discord bots, automation tooling, and modern web applications**. I ship end-to-end — from slash-command design and database schemas to Docker images and cloud deployment.

- 🤖 **Discord ecosystem specialist** — 30+ bots and tools built with `discord.js v14` and `discord.py 2.x` (invite tracking, music, security, crypto wallets, temp-mail, giveaways, ticketing).
- 🌐 **Modern web stack** — Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, Prisma, Zustand and TanStack Query.
- ☁️ **Deployment-first mindset** — every project ships with `Dockerfile`, `nixpacks.toml` or `railway.json` so it can go live in minutes on Railway, Vercel, Netlify or any container host.
- 🔐 **Interested in** security tooling, blockchain payment automation (BTC / LTC / SOL / USDT), and developer productivity.
- 💬 **Ask me about** discord.js, discord.py, Lavalink, Prisma, Railway, Bun, or how to structure a scalable bot codebase.
- 📫 **Reach me** at [arsh.raj.0713@gmail.com](mailto:arsh.raj.0713@gmail.com) or on [Discord](https://discord.gg/MAExCtnuu6).

> **Note:** I work across two GitHub accounts — [`Arsh0712`](https://github.com/Arsh0712) (primary) and [`arshraj0714-commits`](https://github.com/arshraj0714-commits) (active project account). Most recent work lives on the second one.
